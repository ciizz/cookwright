**Design choices worth a reviewer's eye:**
- **Metadata read:** an annotated tag's contents come from one `for-each-ref refs/tags/<name> --format=%(contents)` call per tag, keeping the listing format exactly as the plan states.
- **Signature blocks:** any `-----BEGIN … SIGNATURE-----` line is dropped from that line on (PGP and SSH alike). Neither is measured, since there is no key on this machine.
- **`changelogState`:** returns `{ state, tags (a count), generated }`. It takes an optional precomputed render so the command renders once.
- **No-op writes:** the default mode writes only when the bytes differ; a test asserts the mtime is unchanged on a second run.
- **`--check` output:** the current line goes to stdout, the three drift lines to stderr. Every line is prefixed with the file path.
- **Count lines:** the render says "1 commit" and "N commits" instead of the plan's literal "commit(s)". The `--unreleased` count line reads `_M internal (…)._`, since "in this release" would be wrong there.
- **`oneLine`:** now exported from `doctor/repo.mjs`, so the command words a config load error the way doctor does.
- **Strings test:** it scans `src/changelog.mjs` and `src/lib/changelog`. An `EXEMPT` list skips `src/lib/changelog/render.mjs`, whose text is content of the generated file.
