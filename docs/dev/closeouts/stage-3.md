Ownership is by link text, never by resolution: a link of our shape that resolves is `kept`, one that does not is `kept, not installed where it points (npm install)` or `updated` when it is misdirected, a text in `POINTER_TEXTS_PAST` (empty in this stage) is an earlier pointer, and any other link, dangling or resolving, like a real file or directory, is the user's: `skipped` naming it, and doctor WARNs; a pointer is replaced through a sibling temporary link renamed over it, and a filesystem that refuses symbolic links gives one `not written` line after the rows and init goes on (B-010). init never refuses on the package's absence: a pointer written before `npm install` is a correct link that resolves later.
